- Source: Optical Recognition of Handwritten Digits, UCI, https://doi.org/10.24432/C50P49
- Dataset license: Creative Commons Attribution 4.0, https://creativecommons.org/licenses/by/4.0/
- Vendored subset: https://github.com/scikit-learn/scikit-learn/blob/main/sklearn/datasets/data/digits.csv.gz
- Git blob: `e191a13019b607d4477d1031503ab46218e21040`
- SHA-256: `09f66e6debdee2cd2b5ae59e0d6abbb73fc2b0e0185d2e1957e9ebb51e23aa22`
- 57,523 compressed bytes; 1,797 rows, 64 pixel columns followed by digit label.

Raw compressed bytes are unmodified. The experiment normalizes pixel values by 16 and creates new random stratified splits; these are not the original writer-independent UCI partitions. No private user or employer data is included.
